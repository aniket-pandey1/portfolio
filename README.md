# Portfolio

🔗 **Live Demo:** [https://aniket-pandey1.github.io/portfolio/](https://aniket-pandey1.github.io/portfolio/)

## ✨ Features

- **Dark Futuristic Design** — Sleek dark theme with neon cyan & purple accents
- **Interactive Particle System** — Canvas-based neural network visualization with mouse interaction
- **Glassmorphism UI** — Modern frosted glass cards with backdrop blur
- **Typewriter Effect** — Animated role titles in the hero section
- **Scroll Reveal Animations** — Elements animate into view as you scroll
- **Animated Stats Counter** — Numbers count up when scrolled into view
- **Fully Responsive** — Optimized for desktop, tablet, and mobile
- **Contact Form** — Ready-to-integrate contact form

## 🛠 Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (Canvas API, Intersection Observer)
- Google Fonts (Inter, Space Grotesk, JetBrains Mono)
